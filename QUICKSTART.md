# NewChecklist - Quick Start Guide

## Getting Started

### 1. Authentication
1. Navigate to the login page
2. Sign up with your email and password
3. Verify your email (if required)
4. You're all set!

---

## Daily Usage

### Creating Tasks
1. Enter task title in the input field
2. Select a category (Daily, Weekly, Personal, Work, etc.)
3. Click "+" button or press Enter
4. Task appears instantly with real-time sync

### Managing Tasks
- **Complete Task**: Click the ✓ button to mark as done
- **Reject Task**: Click the ✗ button to reject
- **Delete Task**: Click the trash icon (hover to reveal)
- **Undo Status**: Click status button again to reset to pending

### Organizing with Groups
1. Go to "Grupos" section
2. Type group name
3. Choose a color
4. Click "+" to create
5. Assign tasks to groups by filtering
6. View group-specific tasks by clicking group name

### Filtering Tasks
1. Click the "Filtros" button in task header
2. Select status:
   - **Todas**: Show all tasks
   - **Pendentes**: Only pending tasks
   - **Concluídas**: Only completed tasks
   - **Rejeitadas**: Only rejected tasks
3. Filter resets when you close checklist

### Using Categories
- **Daily**: Recurring daily tasks
- **Weekly**: Tasks for the week
- **Monthly**: Monthly tasks
- **Personal**: Personal projects
- **Work**: Work-related tasks
- **Shopping**: Shopping lists
- **Other**: Miscellaneous

## Customization

### Accessing Preferences
1. Click the gear/settings icon in the header
2. Preferences panel opens
3. Customize and save

### Themes
1. Choose from 5 presets:
   - **Ocean**: Cool blues and teals
   - **Forest**: Green natural theme
   - **Sunset**: Warm oranges
   - **Purple**: Purple gradient
   - **Rose**: Pink/rose colors

2. Or customize individual colors:
   - **Primary Color**: Main accent color
   - **Secondary Color**: Supporting color
   - **Accent Color**: Highlight color

### Other Settings
- **Font**: Choose your preferred font family
- **Border Radius**: Adjust corner roundedness
- **Dark Mode**: Toggle light/dark theme

### Saving
Click "Salvar Preferências" to save all changes. They persist across sessions.

## Common Issues

### Tasks Not Appearing?
1. Check your internet connection
2. Verify you're viewing the correct group filter
3. Refresh the page
4. Check browser console for errors

### Preferences Not Saving?
1. Ensure you clicked "Salvar Preferências"
2. Check your internet connection
3. Verify you're logged in
4. Try closing and reopening preferences panel

### Real-time Not Working?
1. Check browser connection
2. Verify WebSocket is enabled
3. Check Supabase status page
4. Refresh the page

## Security & Privacy

### Your Data
- All data encrypted in transit (HTTPS)
- Database-level access control (RLS)
- Only you can see your tasks
- No data sharing without explicit permission

### Password
- Use strong, unique password
- Change password in Supabase auth
- Never share your password

### Logout
- Always logout when done
- Especially important on shared computers
- Use Settings > Logout button
